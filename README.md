# 🖼️ IbrahimNFT — Basic NFT Project (Web3 Day36)

## 📚 Overview
This project is part of my **Web3 daily learning journey (Day 36)**.  
It demonstrates how to **build, deploy, and mint NFTs** using **OpenZeppelin** smart contracts and **IPFS metadata storage**.

---

## ⚙️ Tech Stack
- Solidity (v0.8.x)  
- Remix IDE  
- OpenZeppelin Contracts  
- IPFS (via Pinata)  
- Sepolia Testnet  
- MetaMask  

---

## 🪙 Features
- Mint NFTs with custom metadata  
- Metadata hosted on **IPFS**  
- Fully compatible with **ERC721 standard**  
- Owner-only minting control  
- Uses OpenZeppelin’s secure **ERC721** and **Ownable** libraries
